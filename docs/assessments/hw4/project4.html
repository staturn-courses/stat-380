Researchers are interested in investigating whether exposure to different volatile compounds influences the growth of southern magnolia seedlings. Previous research on volatile compounds and ambrosia beetles has motivated interest in understanding how these compounds interact with plants. Researchers conduct an experiment with a completely randomized design (CRD) in which seedlings are randomly assigned to one of three treatments:

  • Control

  • Ethanol

  • Methanol

There were 90 seeds available for the experiment, and each treatment randomly received 30 seeds. After a specified exposure period, researchers measure the root length (cm) of each seedling.

Suppose the following partial ANOVA table is obtained from the experiment.

ANOVA Table
Source DF Sums of Squares Mean Square F Pr(>F)
Treatment 240
Error 360
Total

Part 1: One-way ANOVA

  1. Identify the experimental design and write an appropriate statistical model for this experiment in terms of \(Y_{ij}\). Define all parameters in your model and the model assumptions.
  2. Fill in the missing values of the ANOVA table above and show how each value is calculated. Use MS.G and MS.R when defining mean square for Treatment and Error, respectively. Recall that not every position in the table will contain a value. Pr(>F) represents the p-value of F under \(H_0\).
  3. State the null and alternative hypothesis represented by Pr(>F)using \(\mu_y\) and \(\mu_z\) in the alternative (i.e., HA: \(\mu_y\) and \(\mu_z\) are not equal for any \(y\neq z\)), and identify the appropriate degrees of freedom for this F distribution.
  4. Write an appropriate conclusion in the context of the research question using the p-value. Use a significance level of \(\alpha=0.05\)

Part 2: Linear Contrasts

Researchers are particularly interested in comparing the control treatment against the two volatile treatments. One reasonable contrast is the difference between the control and the average of the other two treatments. This is provided below:

\[ \ell_1 = \mu_C - \frac{\mu_E + \mu_M}{2} \]

where (C), (E), and (M) represent the control, ethanol, and methanol treatments, respectively. Let the following sample means be observed: \(\bar{y}_C=13.7\), \(\bar{y}_E=20.0\), and \(\bar{y}_M=26.3\).

  1. Write the linear contrast for \(\hat{\ell}_1\) in terms of \(\bar{y}_{i}\).
  2. Derive \(V(\hat{\ell_1})\) using the model you identified in Problem (1) in terms of \(\sigma^2\).
  3. Explain how to use the ANOVA Table and \(V(\hat{\ell}_1)\) to produce the standard error for \(\hat{\ell}_1\). Compute this quantity.
  4. Consider the test \[H_0: \ell_1=0\ \text{vs}\ H_A:\ell_1\neq 0\] Perform this test by computing a p-value and write an interpretation using the context of the research question. Use a significance level of \(\alpha=0.05\)
  5. Two linear contrasts, \(\ell_1=\sum_{i=1}^k a_i\mu_i\) and \(\ell_2=\sum_{i=1}^k b_i\mu_i\), are orthogonal when \(\sum_{i=1}^ka_ib_i=0\). Identify one reasonable contrast, \(\ell_2\) that is not orthogonal to \(\ell_1\) and carry out the test \(H_0: \ell_2=0\) vs. \(H_A:\ell_2\neq 0\). Interpret the meaning of this test using the context of the research question.
  6. List all possible pairwise comparisons and write the linear contrast for each one. You do not need to carry out these tests. If no p-value adjustment is used, what the probability of there being at least one Type I error? Which multiple comparison procedure discussed in class would you recommend, and why?
